# Datos de movilidad

Este directorio conserva exclusivamente los trazos de las rutas y los archivos de paradas de la aplicación anterior.

- `tepic-routes.json`: geometría de rutas.
- `stops/`: archivos JSON de paradas disponibles.

Los horarios, frecuencias y tarifas no están verificados como datos oficiales y no se incluyen como fuente de verdad.
